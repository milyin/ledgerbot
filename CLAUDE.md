# CLAUDE.md

This repository contains a single Rust crate, `ledgerbot`, a Telegram expense tracking bot built on `teloxide` and `telluride`.

## Build and test

```bash
cargo build
cargo test
./build.sh
```

Run locally with:

```bash
cp .env.example .env
RUST_LOG=debug cargo run --package ledgerbot -- --persistent-storage
```

## Architecture

### Command flow

- `commands/mod.rs` defines the top-level `Command` enum and shared dispatch.
- Command modules in `ledgerbot/src/commands/command_*.rs` are plain structs with:
  - `parse_arguments()`
  - `to_command_string()`
  - `execute()` generated by helper macros in `commands/support.rs`
  - `run0/run1/...` methods for progressive interactive flows
- `ui.rs` provides `CommandContext`, typed callback packing, and menu button helpers.
- Inline keyboard callbacks store typed `Command` values through telluride `CallbackKey` + `InMemStore`.

### Message handling

1. Direct single-line commands are parsed by teloxide in `main.rs` / `handlers.rs`.
2. Multiline and forwarded messages still go through `handle_text_message()`.
3. `utils/parse_expenses.rs` parses mixed input into commands and expenses.
4. `batch.rs` preserves ledgerbot's delayed batch execution for multiline and forwarded input.

### Storage

- Storage traits live in `storage_traits.rs`.
- Chat-scoped stores are implemented in `data_store.rs` and `storages/`.
- Persistent YAML-backed stores are used when `--persistent-storage` is enabled.

### Menus

- Interactive menus live in `ledgerbot/src/menus/`.
- Menu buttons now carry typed `Command` values instead of legacy callback strings.
- `select_word.rs`, `select_category.rs`, `select_period.rs`, and related helpers implement the multi-step command UX.

## Implementation notes

- Categories are regex-based and matched case-insensitively.
- Expenses can use explicit dates or message timestamps.
- Reports support comparisons between periods and paginated category drill-down.
- Follow mode can read another chat's data, but write operations remain local to the current chat.

## Testing focus

Preserve coverage for:

- command parsing and command-string round trips
- category and expense storage behavior
- batching behavior for multiline and forwarded input
- interactive menu flows and callback-driven command execution
